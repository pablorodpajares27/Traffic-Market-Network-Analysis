# Sample Outputs

This folder contains lightweight five-row previews of the final analytical results.

- `Traffic_Market_Network_Analysis_sample_outputs.xlsx` — complete corrected workbook.
- `itineraries/` — eight O&D market outputs.
- `segments/` — six segment summaries plus `bridge_od_city_segment`.
- `dimensions/` — airport, city-market, WAC and period lookup tables.

The corrected `segment_network_summary` and the new analytical O&D–segment bridge are included.
